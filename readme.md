# fastapi 博客系统

## 后端 api 开发

python 生态 ai -> web backend fastapi 有市场

fastapi 快速用于 api 服务的 web 转化 简单
nestjs 企业级别后端服务 复杂

### 后端 api 构成

- http 服务
    nestjs 3000 端口
    fastapi 8000 端口
- 数据库
    sqlite 关系型数据库 轻量级别文本型
    .db 文件可以随程序发布 不像 mysql、postgresql 等数据库需要独立部署

    - orm 框架 对象关系映射
        sqlalchemy 是一个 python 数据库工具包
- 路由
    restful api

### 目录文件的意义

- main.py 单点入口 + 路由注册
- database.py 数据库引擎（驱动）、会话、Base 基础类、get_db

ORM 工具
- models.py 数据库模型类 表做对象
- schemas.py 数据验证和序列化 约束验证 新建一个用户，满足则创建用户
- crud.py 数据库操作

- api 文档
    fastapi 自动生成 api 文档 文档地址 http://localhost:8000/docs

## 启动 http server

uvicorn main:app --reload
uvicorn ASGI 服务器 负责把你的 fastapi 应用实例启动起来
负责把你的 FastAPI 应用跑起来

ASGI（Asynchronous Gateway Interface）异步网关接口

## 常见的状态码

- 2xx 成功
    - 200 请求成功，正常返回数据
    - 201 创建成功，服务端创建了新的资源，返回资源的 URL
    - 204 无内容，服务端成功处理了请求，但是没有返回任何数据，比如删除资源、登出等
- 3xx 重定向
    - 301 永久重定向，浏览器会缓存跳转关系，后续直接范文新的 URL
    - 302 临时重定向，不缓存跳转关系，每次请求都需要服务器返回跳转指令
    - 307 临时重定向，不缓存跳转关系，每次请求都需要服务器返回跳转指令，但是请求方法保持不变
    - 303 临时重定向，资源创建 / 操作完成，请用 GET 方法去另一个地址拿结果
- 4xx 客户端错误（前端/用户问题）
    - 400 请求参数/格式错误，比如后端需要两个参数，但是前端请求时只传了一个参数
    - 401 未授权，用户没有权限访问该资源，比如用户没有登录，token 无效
    - 403 禁止访问，用户有权限，但是没有访问该资源的权限，比如用户没有权限访问管理员资源
    - 404 资源不存在，比如用户请求的页面不存在
    - 405 请求方法错误，比如 get 接口用 post 请求
- 5xx 服务端错误
    - 500 服务器内部错误，比如数据库连接失败、服务器崩溃等
    - 502 网关错误，比如代理服务器或网关服务器返回了无效的响应
    - 504 网关超时，比如代理服务器或网关服务器响应超时
    - 505 HTTP 版本不受支持，比如服务器不支持 HTTP/2 协议
